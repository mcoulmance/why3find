  `why3find.opam`, `vscode/VERSION` and `vscode/package.json`.
- Check the output of `dune exec -- why3find --version`.
- Commit the changes on the `master` branch or a release specific branch.

## Git tag

- Create a git tag with `git tag -a $version -m "version $version"`
- Push it to gitlab with `git push --tags`
- This push started a new `tag` pipeline, run the  `vscode-extension` job in
  this pipeline to produce the `vscode/why3-platform-x.y.z.vsix`

## Add to opam

- You need to have a Github account and to open a PR on
  [https://github.com/ocaml/opam-repository](opam-repository)

Using `opam publish` plugin:

- You'll need a valid [https://github.com/settings/tokens](Github token)
  with `public_repo` scope.
- Run `opam publish https://git.frama-c.com/pub/why3find/-/archive/$version/why3find-$version.tar.gz`, that is the link generated by the Gitlab release.
- Check and validate the informations presented by opam publish.

- Watch over the opam-repository CI and get the PR merged.
